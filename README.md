**Студент:** Гнатишин Богдан, група КІ-404
**Варіант:** 4 (Мова: Rust, Система складання: Cargo, Тестування: cargo test)

## Опис проєкту
Цей репозиторій містить ШІ-агента, який автоматично генерує, збирає та тестує кросплатформний проєкт Hello World мовою Rust, а також створює CI/CD пайплайн (GitHub Actions).

## Запуск агента
Для запуску агента та автоматичної генерації проєкту:
1. Відкрийте чат GitHub Copilot у VS Code.
2. Введіть команду: `@workspace Прочитай маніфест агента в .github/agents/build-engineer.agent.md. Відкрий файл .github/prompts/init.prompt.md і послідовно виконай команду init (усі 5 кроків).`

Для локальної перевірки збірки та тестів (потрібен встановлений Rust):
`bash
cargo clean
cargo build
cargo test
`
